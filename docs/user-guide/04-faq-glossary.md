## সাধারণ প্রশ্ন

**প্রশ্ন: আবেদন করতে কি অফিসে যেতে হবে?**
না। পুরো আবেদন অনলাইনে করা যায় ([ক৪](01-getting-started.md#a4))।

**প্রশ্ন: আমার ইমেইল নেই। কী করব?**
ইমেইল আবশ্যক, কারণ পাসওয়ার্ড ও ফলাফল ইমেইলে আসে। পরিবারের কারো সাহায্যে একটি
বিনামূল্যের Gmail অ্যাকাউন্ট খুলে নিন — আর তার পাসওয়ার্ড মনে রাখুন।

**প্রশ্ন: আবেদন অর্ধেক পূরণ করে বন্ধ করে দিয়েছি। সব হারিয়ে গেছে?**
না। একই ফোন/কম্পিউটারে একই ব্রাউজারে আবার খুললে তথ্য ফিরে আসবে। শুধু সংযুক্ত
ফাইলগুলো আবার দিতে হবে।

**প্রশ্ন: আবেদনের ফলাফল কবে পাব?**
সাধারণত **২০ কর্মদিবসের মধ্যে** ইমেইলে জানানো হয়।

**প্রশ্ন: কী দিয়ে লগইন করব?**
সদস্য হলে মোবাইল নম্বর, ইমেইল বা সদস্য আইডি — যেকোনো একটি। কমিটির সদস্য হলে ইমেইল।

**প্রশ্ন: আমি বিদেশে থাকি। কীভাবে চাঁদা দেব?**
বাংলাদেশে থাকা আত্মীয় আপনার হয়ে টাকা পাঠাতে পারেন। আপনি অ্যাপে সেই লেনদেনের
ট্রানজেকশন আইডি ও স্ক্রিনশট জমা দিন ([খ৪](02-member-guide.md#b4))। লগইনে বিদেশি
নম্বর দিলে + ও দেশের কোড লিখুন।

**প্রশ্ন: টাকা পাঠিয়েছি, কিন্তু এখনো বকেয়া দেখাচ্ছে কেন?**
অফিস যাচাই না করা পর্যন্ত পেমেন্ট **যাচাই চলছে** থাকে। গৃহীত হলে বকেয়া কমে যাবে।
অনেক দিন পরও না বদলালে ট্রানজেকশন আইডিসহ অফিসে যোগাযোগ করুন।

**প্রশ্ন: ভুল তথ্য দিয়ে পেমেন্ট জমা দিয়েছি।**
অফিস সেটা **বাতিল** করবে এবং কারণ জানাবে। তারপর সঠিক তথ্য দিয়ে আবার জমা দিন।

**প্রশ্ন: আমার প্রোফাইলের তথ্য ভুল। নিজে বদলাতে পারি?**
অনুমোদিত তথ্য নিজে বদলানো যায় না। অফিসে জানান। জমির তথ্যের জন্য
[সংশোধনের অনুরোধ](02-member-guide.md#b7) পাঠান।

**প্রশ্ন: আমার মেনুতে কিছু পাতা নেই যা অন্যদের আছে।**
পাতা দেখা যায় দায়িত্ব অনুযায়ী। সাধারণ সদস্যরা প্রশাসনের পাতা দেখেন না — এটা স্বাভাবিক।

**প্রশ্ন: মোবাইলে অ্যাপ আছে?**
ওয়েবসাইট মোবাইল ব্রাউজারে পুরোপুরি চলে। ব্রাউজারের মেনু থেকে **Add to Home screen**
করলে অ্যাপের মতো আইকন পাবেন।

## ত্রুটির বার্তা ও করণীয়

| বার্তা | মানে | করণীয় |
|---|---|---|
| মোবাইল/ইমেইল/সদস্য আইডি অথবা পাসওয়ার্ড সঠিক নয় | লগইনের তথ্য মেলেনি | বানান দেখুন; না হলে [পাসওয়ার্ড রিসেট](01-getting-started.md#a6) |
| অনেকবার চেষ্টা হয়েছে, ১৫ মিনিট পরে আবার চেষ্টা করুন | নিরাপত্তার জন্য সাময়িক বন্ধ | ১৫ মিনিট অপেক্ষা করুন |
| সঠিক ট্রানজেকশন আইডি দিন (৪–৬৪ অক্ষর/সংখ্যা) | আইডির গঠন ভুল | SMS থেকে হুবহু লিখুন |
| শুধু JPG, PNG বা PDF ফাইল দেওয়া যাবে | ফাইলের ধরন ভুল | ছবি বা PDF দিন |
| ফাইল ৫ MB-এর বেশি হতে পারবে না | ফাইল বড় | ছোট ছবি বা স্ক্রিনশট দিন |
| পরিশোধ জমা দেওয়া যায়নি। আবার চেষ্টা করুন। | সংযোগ বা সার্ভারের সমস্যা | কিছুক্ষণ পর আবার চেষ্টা করুন |
| তথ্য লোড করা যায়নি। | ইন্টারনেট বা সার্ভারের সমস্যা | ইন্টারনেট দেখে পাতা রিফ্রেশ করুন |
| বিদেশের দেশ, শহর ও ঠিকানা লিখুন। | বিদেশের ঠিকানা অসম্পূর্ণ | তিনটি ঘরই পূরণ করুন |
| 403 / অনুমতি নেই | এই পাতা আপনার জন্য নয় | প্রয়োজনে সুপার অ্যাডমিনকে জানান |

| সদস্য আইডি | Member ID | অনুমোদনের পর পাওয়া আপনার স্থায়ী নম্বর |
| রেফারেন্স নম্বর | Reference number | আবেদন জমার পর পাওয়া নম্বর |
| চাঁদা / কিস্তি | Subscription / Installment | মাসিক সদস্য ফি |
| বকেয়া | Due | যে টাকা এখনো দেওয়া হয়নি |
| খরচের ভাগ | Cost share | সোসাইটির কোনো কাজের খরচে আপনার অংশ |
| অন্যান্য ফি | Other fees | চাঁদা ছাড়া অন্য ফি (যেমন পিকনিক) |
| ট্রানজেকশন আইডি (TrxID) | Transaction ID | বিকাশ/নগদ/রকেটে টাকা পাঠালে SMS-এ পাওয়া কোড |
| রসিদ নম্বর | Receipt number | ক্যাশ/ব্যাংকে দেওয়া টাকার রসিদের নম্বর |
| যাচাই চলছে | Pending verification | অফিস এখনো মিলিয়ে দেখেনি |
| গৃহীত | Approved | অফিস নিশ্চিত করেছে |
| বাতিল | Rejected | গ্রহণ করা হয়নি |
| সংশোধনের জন্য ফেরত | Returned for correction | কিছু তথ্য ঠিক করে আবার জমা দিতে হবে |
| খতিয়ান | Khatian | জমির মালিকানার সরকারি রেকর্ড |
| দাগ নম্বর (CS/RS) | Dag / plot number | জরিপে জমির নম্বর (CS ও RS জরিপ) |
| হোল্ডিং নম্বর | Holding number | বাড়ি-জমির স্থানীয় সরকারি নম্বর |
| সহ-মালিক | Co-owner | যৌথভাবে জমির মালিক |
| নমিনি | Nominee | আপনার অবর্তমানে যিনি সুবিধা পাবেন |
| রেজোলিউশন বুক | Resolution book | সভার সিদ্ধান্তের খাতা |
| গঠনতন্ত্র | Constitution | সোসাইটির নিয়মের মূল দলিল |
| সুপার অ্যাডমিন | Super admin | সর্বোচ্চ অনুমতিপ্রাপ্ত প্রশাসক |
| অডিট লগ | Audit log | কে কী বদলেছে তার স্বয়ংক্রিয় খাতা |
